# Portfolio
Personal Portfolio by Helitha Rupasinghe.

## Getting Started

Clone the repository.

```
git clone https://github.com/JavascriptDon/Portfolio
```

Install dependencies:
```
$ npm install
```

Launch the Development instance: 

```
$ npm start
```

Once it's running, open your browser and start explorting the app at http://localhost:3000.
